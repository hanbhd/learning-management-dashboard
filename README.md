# Learning Management Dashboard

Demo-Anwendung mit simulierten Daten zur Verwaltung von Kursen, Teilnehmenden und Lernzuweisungen. Das Dashboard zeigt Status, Fortschritt und Auswertungen und bildet typische Abläufe eines Lernmanagementsystems beispielhaft ab.

## Funktionen

- Teilnehmende anlegen, bearbeiten und löschen
- Kurse erstellen, verwalten und löschen
- Kurse Teilnehmenden zuweisen
- Zuweisungen nach Status, Abteilung und Berufsbezeichnung filtern
- Lernfortschritte und Status einzelner Zuweisungen anzeigen
- Abschlussquoten nach Abteilung auswerten
- Zuweisungsanteile pro Kurs darstellen
- Demo-Daten zurücksetzen oder löschen

## Verwendete Technologien

- Angular
- TypeScript
- HTML
- CSS

## Datenspeicherung

Die Anwendung verwendet ausschließlich lokale Beispieldaten im Arbeitsspeicher. Änderungen gelten nur während der laufenden Sitzung und werden nach einem Neuladen der Anwendung zurückgesetzt. Es werden keine Daten an externe Dienste übertragen.
